# Event Data Contract

## Purpose
  This document defines the structure and rules for the events generated by the e-commerece application.
the contract ensures that events produced by an application have a consistent structure before they are sent to the streaming pipeline.
The contract will be used for event generation, validation, streaming processing and data quality checks.

## Event Structure 
  Each event represents an action that occurred in the e-commerce application

  Examples:
   - PRODUCT_VIEW
   - ADD_TO_CART
   - ORDER_CREATED
   - PAYMENT_SUCCESS
   - ORDER_CANCELLED
   - ORDER_SHIPPED
   - ORDER_DELIVERED
   - ORDER_RETURNED

## Field Definitions

| Field | Data Type | Required | Description |
|-------|-----------|----------|-------------|
| event_id | string | yes | unique |
| event_type | string | yes | type of action that occurred |
| customer_id | string | yes | Customer Associated with the event |
| product_id | String | conditional | product associated with the event |
| order_id | string | conditional | order associated with the event |
| event_timestamp | timestamp | yes | time when the event occured |
